## 一、 游戏网络延迟三大核心指标：RTT、抖动（Jitter）与数据包丢失

在 MOBA 竞技游戏中，玩家对网络环境的感知极其敏锐：
- **往返时延（RTT / Ping）**：数据包从本机网卡出发，途经公网路由器抵达腾讯或拳头游戏边缘机房，再返回本机所需的总毫秒数（优秀标准为 < 30ms）；
- **网络抖动（Jitter）**：连续数据包到达时延的离散波动差。如果上一秒 Ping 是 20ms，下一秒突变到 120ms，即使平均延迟不高，操作也会出现明显的“瞬移漂移”；
- **丢包率（Packet Loss）**：因路由器缓冲区溢出或骨干网拥堵导致的游戏状态包被强行丢弃。
卡盟售卖的非法私服节点通常使用低廉的共享 VPS，多人共用下带宽极易被打满，不仅无法降低延迟，反而成为被反作弊系统标记为外挂代理的罪证。

## 二、 本地路由器与 Windows 系统级网络优化实操

无需花费冤枉钱购买来路不明的黑卡盟代理，按以下三步可优化本地网络：
1. **禁用 Windows 网络节流（Network Throttling）**：Windows 默认会限制非多媒体程序的后台网络发包频率，通过注册表将 `NetworkThrottlingIndex` 设定为 `0xFFFFFFFF` 彻底放行游戏数据包；
2. **禁用 Nagle 算法（TCP/UDP 极速发包）**：在注册表对应的网卡接口子项中新建 `TcpAckFrequency` 与 `TCPNoDelay` 并赋值为 1，强行让网卡即刻发出控制指令包，绝不等待数据积攒打包；
3. **路由器启用 QoS 智能流控**：在家庭路由器后台开启 QoS，将本机的 MAC 地址或英雄联盟通信端口（UDP 5000-5500）优先级设定为 **最高（Highest）**，杜绝局域网内其他设备下载看视频导致的瞬间跳 Ping。
